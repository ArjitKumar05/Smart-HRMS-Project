# 🚀 Smart HRMS Portal (B.Tech Full-Stack Project)

A Full-Stack Human Resources Management System (HRMS) web application designed to manage employee records, automate monthly payroll & tax calculations, and track upcoming public holidays using real-time REST APIs.

## 🔗 Live Demo
* **Live Website:** [https://arjitkumar05.github.io/Smart-HRMS-Project/](https://arjitkumar05.github.io/Smart-HRMS-Project/)

## 📌 About the Project
This project is a comprehensive Human Resources Management web application built to streamline core HR operations. It features an interactive employee directory with CRUD operations, automated monthly salary & tax processing, and real-time public holiday tracking.

## ✨ Features
* **Employee Management (CRUD):** Add, view, and remove employees with dynamic profile avatars.
* **Dynamic Payroll Calculator:** Automatically computes monthly net salary after accounting for approved leaves, provident fund (PF), and tax deductions.
* **Public Holiday API Integration:** Fetches and displays upcoming public holidays in real-time using external REST APIs.
* **Persistent Storage:** Utilizes browser LocalStorage to seamlessly save and manage employee records across sessions.
* **Modern UI:** Built with Tailwind CSS for a clean, fully responsive, and professional dashboard interface.
